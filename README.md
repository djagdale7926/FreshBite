
# 🍔 FreshBite – Online Food Ordering Website

FreshBite is a responsive food ordering website built using HTML, CSS, and JavaScript. It allows users to browse food, manage their cart, and simulate checkout.

# 🌐 Live Demo
[View FreshBite](https://djagdale7926.github.io/FreshBite/)

## ✨ Features
- Responsive design for desktop and mobile
- Food menu and restaurant listings
- Add, remove, and update cart items
- Automatic price and delivery fee calculation
- Demo login and registration
- Checkout and order confirmation

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📂 Project Structure
FreshBite/
├── index.html
├── cart.html
├── checkout.html
├── login.html
├── register.html
├── CSS.css
├── script.js
└── images/

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Run `index.html` using Live Server.

## ⚠️ Note
This is a frontend-only project. Login, registration, and payments are simulated.
